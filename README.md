# Лабораторная работа 3. Модели бизнес-процессов

**Тема:** организация тренировок и учёт результатов любительского бильярдного клуба.

**Команда 19:** Борисюк Е. Г. (К3340), Езиева Милана, Федорова Мария, Петрова Мария, Муравьев Матвей.

Основа - [концепция из работы 2](https://github.com/Doney888/PrIS/tree/lab02-concept), вариант C: собственное веб-приложение. Модель сохраняет границы и учебные допущения предыдущей работы.

## Результат

- [PDF-отчёт](output/Laba_3_Komanda_19_Otchet.pdf): 18 страниц, в том числе 10 векторных диаграмм IDEF0.
- Контекст A-0 и первый уровень A0 из пяти блоков для AS-IS и TO-BE.
- Декомпозиции A2, A3, A4 по четыре блока для каждого состояния. Третий раскрытый блок выполнен как дополнительное задание.
- Пояснения ко всем диаграммам, словарь ICOM, согласование уровней, сравнение и вывод.

Диаграммы оформлены в стиле листов erwin Process Modeler/BPwin, но созданы программно. PDF и JSON не являются родным форматом проекта erwin. Диаграммы в отчёте расположены на листах A3, текстовые страницы - A4; при печати можно выбрать подгонку под бумагу.

## Воспроизведение

Python 3 и `reportlab` (`python -m pip install reportlab`). Генератор использует шрифты Arial и Times New Roman из `C:/Windows/Fonts`.

```powershell
python build_report.py
```

При наличии `model.json` используется его содержимое. Проверяются количество блоков, ссылки на функции, наличие управления и выхода у каждой функции, соответствие граничных интерфейсов дочерних диаграмм интерфейсам родительских блоков. Результат дополнительно проверен визуально.

Сценарий подкаста передан участникам отдельно. Для выполнения этого дополнительного задания необходимо записать аудио.
